关于 ModList-Weaver

◎ 软件信息
ModList-Weaver
版本 v3.3.0
Minecraft 双源（Modrinth + CurseForge）模组迁移工具：扫描旧版本 mods 目录、导出 modlist.json、批量 / 单模组下载。
✦ 作者
LSssT
https://github.com/JonathanSssst
◈ 更新日志
v3.3.0 ▾
2026-08 · 最新正式版
一键更新已安装模组 · 本地 mods 目录管理
  • 【一键更新】新增「本地模组」页：扫描本地 mods 目录后一键检查更新，批量下载最新适配版本并自动移除旧文件，原禁用模组更新后保持禁用状态。
  • 【本地目录管理】支持启用 / 禁用（.disabled 后缀）/ 删除 / 打开源页面 / 查看详情，未识别模组标灰展示。
  • 【更新任务】任务中心新增「模组更新」任务类型，纳入队列 / 进度 / 结算 / 断点恢复体系。
  • 【工程化】新增 /api/manage_scan、/api/manage_mod、/api/download_updates 三个接口。
  • 【测试】新增 tests/test_manage_v33.py，pytest 全绿。
